# Changelog

## 0.1.0 — MVP

- Phase 1: TypeScript pnpm monorepo, CLI foundation, quality tooling, CI.
- Phase 2: deterministic JavaScript/TypeScript error and V8 stack parsing.
- Phase 3: safe source windows, TypeScript diagnostics, dependency metadata.
- Phase 4: bounded Git context and deterministic evidence-based root-cause rules.
- Phase 5: `analyze` command with terminal and JSON reports.
- Phase 6: static configuration, project discovery, focused analysis, watch, and CI mode.
- Phase 7: security hardening, resource limits, release documentation, and regression tests.

Known limitations: DebugLens focuses on common Node.js/V8 diagnostics. It does not perform semantic source analysis, automatic fixes, AI reasoning, or support every JavaScript runtime stack format.
